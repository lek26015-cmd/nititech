CHAPTER 01 // TAXONOMY & RISK LEVEL

CHAPTER 02 // COMPARATIVE TORT JURISPRUDENCE

2. หลัก Strict Liability เทียบกับความประมาทเลินเล่อ (Comparative Tort Law)

ในกฎหมายลักษณะละเมิดตามประมวลกฎหมายแพ่งและพาณิชย์ มาตรา 420 ผู้เสียหายมีภาระการพิสูจน์ (Burden of Proof) ว่าผู้กระทำละเมิดได้กระทำโดยจงใจหรือประมาทเลินเล่อ แต่เนื่องจากลักษณะเฉพาะของโมเดล Generative AI และ Deep Neural Networks ที่ไม่สามารถอธิบายกระบวนการคิดของระบบได้โดยตรง (Explainability Problem) ร่างกฎหมายไทยจึงเสนอให้นำหลัก **ความรับผิดเด็ดขาด (Strict Liability)** มาปรับใช้ในบางสถานการณ์

หลักละเมิดดั้งเดิม (ป.พ.พ. ม.420) CLASSICAL TORT
  • close ผู้เสียหายต้องพิสูจน์ข้อบกพร่องของโค้ด (Bug/Flaw) ซึ่งแทบเป็นไปไม่ได้สำหรับคนทั่วไป
  • close ผู้พัฒนาปฏิเสธความรับผิดได้ง่ายหากอ้างว่าเป็นผลลัพธ์ที่เกิดจากการเรียนรู้ด้วยตนเองของโมเดล

  • check บังคับให้ผู้ประกอบการในกลุ่ม High-Risk ต้องทำประกันภัยความรับผิดต่อบุคคลภายนอก (Mandatory AI Insurance)
CHAPTER 03 // INTELLECTUAL PROPERTY & DATA FEEDS

3. การจัดการลิขสิทธิ์ข้อมูลฝึกสอน (Training Dataset Copyright & Fair Use Doctrine)

ข้อถกเถียงที่ดุเดือดที่สุดในประชาคมวิชาการและผู้สร้างสรรค์คอนเทนต์ไทย คือการนำงานอันมีลิขสิทธิ์ (วรรณกรรม ภาพวาด ภาพถ่าย ดนตรี) ไปทำการคัดลอก ประมวลผล และสกัดเวกเตอร์เพื่อป้อนเข้าเป็นข้อมูลฝึกสอน (Training Sets) ของ Large Language Models (LLMs) และ Diffusion Models ว่าจะเข้าข่ายข้อยกเว้นการละเมิดลิขสิทธิ์ (Fair Use) ตามมาตรา 32 แห่ง พ.ร.บ. ลิขสิทธิ์ หรือไม่

CHAPTER 04 // BENCHMARK MATRIX
